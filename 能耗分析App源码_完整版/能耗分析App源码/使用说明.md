# 能耗分析 App（安卓）源码

安装包装不出来，这份是完整的安卓工程源码。把它整个上传到 GitHub，由 GitHub 免费帮你打包，几十分钟后下载 APK 装到小米14。全程不需要装 Android Studio。

## 第一步：上传 GitHub（约 5 分钟）
1. 手机或电脑打开 github.com，注册/登录（免费）
2. 点右上角 + → New repository，名字随便填，比如 `energy-app`，选 Public，点 Create
3. 在仓库页点 "uploading an existing file"，把 **能耗分析App源码 文件夹里的全部文件**（包括 .github 这个隐藏文件夹）拖进去，点 Commit changes

## 第二步：等它打包（约 10～20 分钟）
1. 仓库上方点 Actions 标签页
2. 左侧点「打包安卓APK」→ 右侧 Run workflow → 绿色按钮 Run workflow
3. 等圆圈变成绿色对勾（首次会久一点，失败就点进去看红色那一步，再点 Re-run）
4. 进入这次运行，页面最下方 Artifacts 里下载 **app-debug-apk**（是个 zip，里面是 app-debug.apk），解压得到 `app-debug.apk`

## 第三步：装到小米14
1. 把 APK 传到手机（微信发给自己 / 数据线 / 网盘都行）
2. 点开 APK，提示"允许安装未知应用"→ 去设置里给「文件管理」（或你点开 APK 用的那个 App）打开这个开关
3. 小米提示"未通过安全检测"时，点「继续安装」/「仍要安装」

## 第一次打开要点什么
- 首次启动设置管理员密码（和电脑版一样）
- 数据存在手机里，**是空的**。要从电脑搬过来：电脑版点「数据备份」导出 JSON → 发到手机 → 手机 App「系统设置 → 数据恢复」选这个文件
- 导出的报表、备份存在手机的「下载 / 能耗分析」文件夹

## 这套代码做了什么
- `app/src/main/python/server/`：你原来的 Python 后端（db/analyze/importer/report/xlsx_io/app），一行业务代码没改；`android_entry.py` 负责在手机里启动它
- `app/src/main/assets/web/`：上一版做好的手机网页，App 在手机内部打开它，**不用联网、不用电脑**
- `app/src/main/java/.../MainActivity.java`：外壳，负责启动 Python、显示页面、把导出文件存到下载目录、选 Excel 文件导入、返回键逐层返回
- `.github/workflows/build-apk.yml`：GitHub 的打包步骤

## 需要注意
- 我只打包了 arm64-v8a（小米14 用这个），安装包约 40～60MB
- 这个 APK 用的是调试签名，能正常用；以后更新版本要先卸载旧的再装
- APK 没有上架应用商店，是侧载安装，公司给外部商户用之前先确认内部规定
- 我是根据 Chaquopy 官方文档写的这套配置，本地没装安卓打包环境，**没能真机编译运行过**，第一次打包如果报错，把 Actions 里的红色报错发给我
